# Kalakaar Studios

Premium talent management and booking site built with Next.js, Tailwind CSS, Framer Motion, GSAP, and React Hook Form.

## What’s inside

- Next.js App Router with TypeScript
- Bright yellow and white visual system with premium red/yellow accents
- Talent profiles, categories, gallery, testimonials, blog, and booking flows
- Form validation with React Hook Form and Zod

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run start
```

## Deploy

This project is ready for a standard Next.js deployment on Vercel.

1. Push the repo to GitHub.
2. Import the repository into Vercel.
3. Keep the default build command: `npm run build`.
4. Use `npm run start` for local production checks.

## Included routes

Home, About, Why Choose Us, Categories, Talent profiles, Gallery, Testimonials, Case Studies, Blog, Booking, Contact, Pricing, FAQ, Privacy, Terms, and a custom 404.
