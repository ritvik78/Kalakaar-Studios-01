# Kalakaar Studios

A glossy, Diet Coke-inspired talent management and booking website built with Next.js, Tailwind CSS, Framer Motion, GSAP, and React Hook Form.

## Stack

- Next.js App Router + TypeScript
- Tailwind CSS with custom metallic/glass animations
- Framer Motion and GSAP for sheen, wipe, and transition effects
- React Hook Form + Zod for booking and contact validation

## Run locally

```bash
npm install
npm run dev
```

## Included routes

Home, About, Why Choose Us, Categories, Talent profiles, Gallery, Testimonials, Case Studies, Blog, Booking, Contact, Pricing, FAQ, Privacy, Terms, and a custom 404.
